# The Solar Co. website concept

Responsive, light-theme lead-generation website based on the supplied logo colours and the attached solar brochure reference.

## Included
- Home hero with high-visibility quote CTA
- Lead-capture form UI
- About Us, Services, Customer Testimonials and FAQ sections
- Solar + battery educational flow
- Responsive navigation and sticky mobile quote CTA
- Brand palette: Navy `#304254`, Deep Navy `#243746`, Orange `#FA9D5A`, Orange Accent `#F58A42`
- DM Sans body type + Manrope display type

## Before production launch
1. Connect the quote form to the client's CRM, email service or API.
2. Replace sample testimonials with verified customer reviews.
3. Add the final phone number, email, privacy policy and terms.
4. Confirm service-area, warranty and product claims before publishing.
5. Replace the lightweight CSS wordmark with the supplied production logo asset if required.

Open `index.html` directly or serve this folder from any static hosting provider.
