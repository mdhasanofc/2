# TerraPro Agri — WordPress Website Concept

A clean, professional informational WordPress theme concept for an agricultural machinery / service business. The design direction is informed by the competitive set supplied by the client (Boxer Agri, Jansen Versand and Geo Agric) while keeping the layout, branding and copy original.

## Design direction
- Modern agricultural visual language: deep green, warm neutral backgrounds, crop/field photography and high-contrast calls to action.
- Service-first information architecture so visitors understand the offer immediately.
- Strong trust layer: expertise, support, after-sales and simple enquiry flow.
- Responsive mobile navigation and fluid typography.
- Fast theme structure with no page-builder dependency required.

## Included homepage sections
1. Sticky navigation + contact CTA
2. Large conversion hero
3. Service / solution category cards
4. Why choose us / trust section
5. Service promise / after-sales section
6. Simple four-step process
7. Contact / enquiry section
8. Full business footer

## WordPress setup
- Upload the `agri-service-wordpress-theme` folder to `/wp-content/themes/` and activate it.
- Set Site Title under Settings > General.
- Business phone, email, location and CTA label are editable under Appearance > Customize > Business Details.
- Assign a menu to `Primary Menu` if custom navigation is required.
- Replace demo photography with licensed client imagery before production launch.

## Recommended production plugins
Use only what the final hosting stack needs:
- SEO: Rank Math or Yoast SEO
- Forms: Fluent Forms, Gravity Forms or Contact Form 7
- Caching/performance: LiteSpeed Cache (LiteSpeed server) or WP Rocket
- Security: Wordfence or host-level WAF/security
- SMTP: FluentSMTP or WP Mail SMTP
- Backups: host backups or UpdraftPlus

## SEO / performance implementation for production
- Unique title + meta description per service page
- One primary H1 per page and clean heading hierarchy
- Organization / LocalBusiness / Service schema as appropriate
- WebP/AVIF images, correct dimensions and lazy loading
- Local fonts or optimized Google Fonts delivery
- Page caching, browser caching and minification where safe
- Sitemap submitted to Google Search Console
- Accessible alt text and form labels

## Browser/device testing
Final production QA should cover current Chrome, Edge, Firefox and Safari plus common Android/iOS breakpoints. Test forms, phone/email links, navigation, Core Web Vitals and 404/redirect behavior before launch.
